# Klaslokaal v18 — testprototype

Nieuwe onderdelen: taalkeuze in navigatie (NL/EN/ES/PT/DE/FR), leerlingkaarten met individuele profielen, leerdoelen, huiswerk en lesgeschiedenis, knop Start les per leerling, compactere classroom-omlijsting met notities.

**Belangrijke beperkingen:** De zes talen zijn toegepast op de navigatie; inhoudelijke pagina's zijn nog niet volledig vertaald. Leerlinggegevens blijven uitsluitend in localStorage in dezelfde browser. Er is nog geen echte login, database, gedeeld teken-/PDF-canvas, automatische lesregistratie of audio-/spreektijdmeting. De v15-classroom is ingebed en zijn bestaande functies zijn niet opnieuw ontworpen. Gebruik alleen fictieve gegevens.

Installatie: upload de inhoud van deze map naar de root van de GitHub repository Klaslokaal2. Verwijder geen mappen; vervang gelijknamige bestanden. Vercel deployt vanaf main. De originele v15-site blijft ongemoeid.
